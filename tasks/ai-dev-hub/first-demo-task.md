# First Demo Task

## 1. 目标

定义 AI Work Hub 第一个可验收 Demo。

该 Demo 是判断系统是否真正可用的最低标准。

## 2. Demo 名称

```text
需求调研任务闭环 Demo
```

## 3. Demo 用户故事

作为一个产品经理，我希望能创建一个需求调研任务，添加资料，调用调研助手生成 prompt，把外部 AI 的结果粘贴回来，并得到一份可编辑、可标记最终版的调研结论。

## 4. Demo 前置条件

系统已经：

```text
完成初始化
安装默认助手模板
安装默认流程模板
有默认 Workspace
有默认 Project / Space
```

## 5. Demo 步骤

### Step 1：进入首页

用户看到：

```text
你想完成什么？
```

并看到任务类型入口。

### Step 2：选择任务类型

用户点击：

```text
做需求调研
```

### Step 3：创建任务

用户填写：

```text
任务标题：调研 AI 工作流工具
任务目标：了解适合产品经理和运营使用的 AI 工作流工具，并给出是否自研的建议。
预期输出：调研结论和下一步建议。
```

系统自动推荐：

```text
默认助手：调研助手
推荐流程：需求调研流程
资料范围：标准
输出类型：调研结论
```

### Step 4：添加资料

用户添加文本资料：

```text
我希望做一个产品/运营使用的 AI 工作台，可以管理任务、资料、助手、流程和输出。
```

资料状态：

```text
重点资料
```

### Step 5：运行调研助手

用户点击：

```text
继续生成
```

系统：

```text
构建上下文
生成 prompt
创建 Run
状态 waiting_user
展示 prompt
```

### Step 6：复制 Prompt

用户点击：

```text
复制 Prompt
```

复制前提示：

```text
请确认 Prompt 中不包含不应发送给外部 AI 的敏感信息。
```

### Step 7：粘贴外部 AI 输出

用户把外部 AI 的回答粘贴回系统。

点击：

```text
保存为输出
```

系统：

```text
Run 状态 success
创建 Output
Output 类型 research_report
版本 v1
```

### Step 8：编辑 Output

用户进入输出详情，修改内容。

点击：

```text
保存新版本
```

系统创建：

```text
调研结论 v2
```

### Step 9：标记最终版

用户点击：

```text
标记最终版
```

系统将 v2 标记为最终输出。

## 6. Demo 验收标准

必须满足：

1. 用户无需先配置助手或流程。
2. 用户可以从任务类型开始。
3. 系统能推荐默认助手。
4. 系统能推荐默认流程。
5. 用户可以添加资料。
6. 用户可以标记重点资料。
7. 系统可以生成 prompt。
8. 用户可以复制 prompt。
9. 用户可以回填外部 AI 输出。
10. 系统可以生成 Output。
11. 用户可以编辑 Output。
12. 用户可以创建新版本。
13. 用户可以标记最终版。
14. 任务详情能展示资料、输出、执行记录。

## 7. 非验收范围

该 Demo 不要求：

```text
运行完整 Workflow Runtime
CLI Assistant
MCP
ChatGPT Action
多用户权限
复杂导出
代码执行
```

## 8. 失败判定

如果出现以下情况，Demo 不通过：

```text
用户必须先创建助手才能开始
用户必须先创建流程才能开始
生成 prompt 后无法回填结果
回填结果后没有 Output
Output 不能编辑
Output 不能标记最终版
任务详情看不到执行记录
```
