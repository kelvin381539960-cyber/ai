# Onboarding 首次启动与初始化向导

## 1. 目标

首次启动必须让用户不配置 Agent / Workflow 也能开始使用。

目标：

```text
第一次打开 → 3 分钟内创建第一个任务 → 生成第一个输出
```

## 2. 首次启动流程

### Step 1：选择运行模式

默认：私有服务器模式。

选项：

```text
私有服务器模式：推荐，公司电脑和个人电脑访问同一地址。
本机模式：仅当前电脑使用。
```

MVP 默认支持私有服务器模式和本机模式的配置表达，实现可先按本机/服务器同构处理。

### Step 2：选择数据目录

用户选择数据保存目录。

默认目录：

```text
~/.ai-work-hub/
```

服务器推荐目录：

```text
/srv/ai-work-hub/
```

目录结构：

```text
.ai-work-hub/
  db.sqlite
  materials/
  outputs/
  runs/
  workflows/
  exports/
```

### Step 3：创建 Workspace

默认 Workspace：

```text
我的工作台
```

用户可改名。

### Step 4：安装默认模板

系统自动安装：

- 默认任务类型。
- 默认助手模板。
- 默认流程模板。
- 默认输出模板。

用户不需要手动创建助手和流程。

### Step 5：进入首页

进入首页后显示：

```text
你想完成什么？
```

并展示任务类型入口。

## 3. 首次启动验收

必须满足：

1. 用户第一次打开系统时有初始化向导。
2. 用户可以选择数据保存位置。
3. 用户可以创建默认 Workspace。
4. 系统自动安装模板。
5. 用户完成向导后可以直接创建任务。
6. 不允许首次进入后出现空白 Agent / Workflow 状态。

## 4. 空状态规则

### 没有任务

显示：

```text
你还没有任务。选择一个任务类型开始。
```

按钮：

```text
创建任务
```

### 没有资料

显示：

```text
这个任务还没有资料。你可以先添加资料，也可以直接让助手根据目标生成初稿。
```

按钮：

```text
添加资料
直接生成
```

### 没有输出

显示：

```text
还没有输出。运行默认助手或任务流程生成第一个结果。
```

按钮：

```text
运行默认助手
运行推荐流程
```

## 5. 默认安装内容

初始化必须写入：

```text
default task types
default assistants
default workflows
default output types
```

详见：

```text
seed-templates.md
```

## 6. 多电脑使用说明

首次启动时必须提示：

```text
如果你希望公司电脑和个人电脑看到同一份任务，请把 AI Work Hub 部署在服务器上，并让两台电脑访问同一个服务地址。
```

MVP 不做复杂账号同步。

数据一致性依赖同一服务实例和同一数据目录。
