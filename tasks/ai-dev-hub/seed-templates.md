# Seed Templates 默认模板

## 1. 目标

系统初始化后必须有可直接使用的默认模板。

用户不应先创建助手或流程才能开始。

## 2. 默认任务类型

必须内置：

```text
research               需求调研
prd                    PRD 生成
competitive_analysis   竞品分析
ops_plan               运营方案
meeting_summary        会议纪要
data_review            数据复盘
review                 评审
tech_question          技术追问
custom                 自定义任务
```

每个任务类型必须包含：

```text
名称
说明
默认问题
默认助手
默认流程
默认输出类型
默认资料范围
```

## 4. 默认流程模板

## 4.1 需求调研流程

```text
确认调研问题
添加调研资料
调研助手生成初稿
评审助手检查遗漏
生成最终调研结论
```

## 4.2 PRD 生成流程

```text
确认需求目标
添加背景资料
PRD 助手生成草稿
评审助手检查问题
生成 PRD 最终草稿
```

## 4.3 竞品分析流程

```text
确认竞品和维度
添加竞品资料
竞品分析助手生成对比
评审助手检查结论
生成跟进建议
```

## 4.4 运营活动流程

```text
确认运营目标
添加历史数据和限制
运营方案助手生成方案
评审助手检查风险
生成执行清单
```

## 4.5 会议纪要流程

```text
添加会议记录
会议纪要助手生成纪要
用户确认行动项
生成最终纪要
```

## 4.6 数据复盘流程

```text
添加数据资料
确认核心指标
数据分析助手生成分析
生成行动建议
```

## 4.7 评审流程

```text
添加待评审内容
确认评审重点
评审助手生成问题清单
用户标记采纳情况
生成最终评审结论
```

## 4.8 技术追问流程

```text
添加技术资料
确认关注点
技术追问助手生成问题清单
补充研发回复
生成产品决策建议
```

## 5. 默认输出类型

必须内置：

```text
research_report
prd_draft
competitive_analysis
ops_plan
meeting_summary
data_review
review_result
action_items
handoff
custom
```

## 6. 模板安装规则

初始化时：

1. 如果没有模板，安装全部默认模板。
2. 如果已有模板，不覆盖用户修改。
3. 提供“恢复默认模板”入口。
4. 默认模板可复制为自定义模板。

## 7. 验收

必须满足：

1. 新用户无需创建助手即可创建调研任务。
2. 新用户无需创建流程即可运行需求调研流程。
3. 默认助手和流程可以被编辑或复制。
4. 默认模板不会覆盖用户自定义内容。
